MONE TINE COFFEE SHOP - VERSION 2

This version is a more realistic frontend website.

FILES
-----
index.html
style.css
script.js

TECHNOLOGIES
------------
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- CSS Flexbox
- CSS Grid through Bootstrap row/columns
- Responsive media queries

FUNCTIONS
---------
1. Responsive navigation menu
2. Menu category filtering
3. Add menu items to order
4. Shopping cart
5. Increase/decrease quantity
6. Remove items
7. Automatic total calculation
8. Order summary modal
9. Customer name validation
10. Demo order submission
11. Contact form validation
12. Toast notifications
13. Responsive mobile layout

IMPORTANT
---------
The ordering system is a FRONTEND DEMO.

It does NOT:
- take real payments
- send orders to a real restaurant
- save orders in a database
- send real emails

To make those functions genuinely production-ready, you would need a backend
such as PHP, Node.js, Python, or another server and a database.

HOW TO RUN
----------
1. Put all three files in the same folder.
2. Open index.html in Chrome.
3. Internet is needed because Bootstrap and the coffee photos are loaded online.

The code is intentionally separated and commented so a beginner can understand
each section instead of having one large compressed file.
